Micro Demessifier v5 — private Supabase sync

1. Upload all files in this folder to the existing GitHub repository, replacing files with the same names.
2. Keep the same GitHub Pages address. This preserves the local browser copy already on your PC.
3. Open Demessifier on the PC that currently has your preferred layout.
4. In the new Sync card, enter an email and a new password and click Create account.
5. If Supabase asks you to confirm your email, do that, return to Demessifier, and click Sign in.
6. The first signed-in device uploads its current local layout to the private Supabase table.
7. On your phone, update/reopen Demessifier, sign in with the same email/password, and it will load the cloud layout.
8. Changes made with Organize > Save are saved locally and to Supabase. Other signed-in devices check for updates when opened/focused and about every 15 seconds.
9. Import/Export still work as backups. Recent items intentionally remain device-local.

Security
--------
The public Supabase publishable key is included in app.js by design. Your Row Level Security policies protect the table. Never put a secret/service-role key or the database password in these files.

Recommended after your account works on both devices
----------------------------------------------------
Because the GitHub Pages app is public, disable new user signups in Supabase Authentication settings after you have created your account. Existing accounts can continue to sign in.
